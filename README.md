# Data Analysis with Python

A beginner-friendly collection of Jupyter notebooks focused on learning Python for data analysis. The notebooks cover core Python concepts, working with datasets, and data wrangling techniques used in everyday analysis workflows.

## Contents

- `01_python_fundamentals.ipynb` — Python basics, variables, operators, data types, and foundational programming concepts
- `02_importing_dataset.ipynb` — importing and reading data into Python
- `03_data_wrangling.ipynb` — cleaning, transforming, and preparing data for analysis
- `python_practice.ipynb` — hands-on Python practice exercises and examples

## Learning goals

- Understand Python fundamentals and syntax
- Work with variables, functions, and basic operators
- Import and inspect data from external sources
- Clean and restructure datasets
- Build a solid base for more advanced data analysis and data science work

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/AbdulRehman393/data-analysis-with-python.git
   cd data-analysis-with-python
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate   # On macOS/Linux
   venv\Scripts\activate      # On Windows
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open any notebook in the repository and run the cells.
